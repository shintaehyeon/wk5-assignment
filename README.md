# OSS 5주차 · 작은 도서관

HTML, CSS, JavaScript로 도서관리 화면과 DOM 연습 페이지를 구현했습니다.
외부 라이브러리, Bootstrap, React, 서버, 데이터베이스, 설치 과정이 없습니다.

## 파일과 실행 방법

아래 파일을 같은 폴더에 두고 `index.html`을 브라우저로 열면 됩니다.

- `index.html`: 홈과 두 실습 페이지 링크
- `js_dynamic.html`: input 값 목록 추가, 입력창 초기화, 항목별 삭제
- `crud.html`: 도서 CRUD와 배열 데이터, JavaScript 포함
- `style.css`: 공통 디자인과 작은 화면 대응
- `README.md`: 기능, 코드 흐름, 학습 및 검증 안내

## 과제 내용

DOM 연습 페이지에서 책 이름을 목록에 추가하고 삭제합니다. 도서관리 페이지에서는
JavaScript 배열을 사용해 도서를 추가하고, 목록을 확인하고, 수정하고, 삭제합니다.

## 도서관리 기능

입력 필드 5개: 도서명, 저자, 분류, 출판사, 가격. ID는 자동 부여합니다.
연습용 가상 도서 3권으로 시작합니다.

- Create: 검증 후 `books.push()`로 추가합니다.
- Read: `renderBooks()`가 기존 표를 비우고 `forEach()`로 배열을 다시 출력합니다.
- Update: `find()`로 책을 찾고 폼에 표시한 뒤, 검증을 거쳐 객체 속성을 바꿉니다.
- Delete: `confirm()`에서 확인한 경우 `filter()`로 해당 ID를 제외합니다.
- `editingId`가 null이면 추가 모드, 숫자이면 해당 도서의 수정 모드입니다.
- 수정 취소 시 원래 데이터는 유지됩니다. 수정 중인 도서를 삭제하면 폼도 초기화됩니다.
- `nextId`를 별도로 증가시켜 삭제 후 추가해도 ID가 겹치지 않습니다.
- 입력값은 `textContent`로 출력하여 HTML 태그가 실행되지 않습니다.

### Create / Update 공통 validation

두 동작 모두 같은 `validate()` 함수를 사용합니다.

1. 필수 항목 누락 및 공백만 입력한 값 차단 (`trim()` 사용).
2. 도서명 길이 2~100자 검사.
3. 저자와 출판사 각각 최대 50자 검사.
4. 허용된 분류 선택 여부 검사.
5. 가격이 0~1,000,000 범위의 정수인지 검사. 빈 가격도 차단.

입력 조건에 맞지 않으면 오류 문구를 보여주고, 잘못된 내용은 도서 목록에 넣지 않습니다.

### DOM 연습

입력한 책 이름을 `createElement()`와 `append()`로 목록에 추가합니다.
입력 초기화는 입력창만 비우며 목록은 유지합니다. 항목의 삭제 버튼은 해당 `li`를
`remove()`로 지웁니다. 공백 입력을 막고, 항목 개수와 빈 목록 안내를 갱신합니다.

## 핵심 학습 내용

1. DOM 요소를 선택하고 이벤트를 연결해 입력과 버튼 동작을 처리합니다.
2. 배열의 `push()`, `find()`, `filter()`로 데이터를 추가·수정·삭제하고, `renderBooks()`로 화면을 갱신합니다.
3. Create와 Update에 같은 입력 검증을 적용해 잘못된 데이터가 배열에 반영되지 않도록 합니다.

## Weekly Review — 본인이 직접 작성

- 내가 직접 수정한 부분: 도서 수정과 삭제가 동작하지 않는 문제를 확인하고, 해당 기능의 코드 흐름을 점검해 수정했습니다.
- Problem & Solution: 수정 저장이나 삭제를 해도 도서 목록에 제대로 반영되지 않는 문제가 있었습니다. 수정은 `editingId`로 선택한 도서를 찾아 기존 정보를 갱신하고, 삭제는 확인 후 해당 ID의 도서를 배열에서 제외하도록 했습니다. 두 작업 뒤 `renderBooks()`를 호출해 변경된 배열이 목록에 다시 표시되도록 했습니다.
- Reflection: 수정 대상은 ID로 구분하고, 수정은 배열의 도서 정보를 갱신하며 삭제는 `filter()`로 해당 도서를 제외한다는 점을 익혔습니다. 데이터와 화면은 별개이므로 배열을 바꾼 뒤 목록을 다시 그려야 변경 사항이 보인다는 것도 배웠습니다.
